# Kevin Phon — Portfolio

This is my personal portfolio as a Computer Science student at Cal Poly Pomona. It brings together my projects, what I am learning, and ways to contact me.

I built the site with help from AI tools and am updating the wording to reflect my background and work more accurately.

[Visit my portfolio](https://Kevin-Phon.github.io/portfolio/)

## What is here

- An introduction to my background and interests in software engineering and AI.
- Technical skills and topics I am currently learning.
- Project summaries, with code and demo links where available.
- Contact information.

## Projects currently featured

- **[FocusFlow Study Dashboard](https://github.com/Kevin-Phon/focusflow-dashboard):** a personal learning project with a Pomodoro timer, a task list, and browser storage.
- **GAZE:** a student team project exploring attention-gated gesture control for physical devices.

The portfolio is a place to follow my progress. Project descriptions should distinguish my own work from team contributions and make clear when work is still in progress.

## How the site is built

The site uses HTML, CSS, and JavaScript, with no frontend framework or package installation.

| File | Purpose |
| --- | --- |
| `index.html` | Page content, navigation, skills, and project summaries |
| `style.css` | Layout, typography, and responsive styles |
| `script.js` | Mobile navigation, section scrolling, and fade-in effects |

Fonts are loaded from Google Fonts. The site is hosted on GitHub Pages.

## Run it locally

Clone the repository and open `index.html` in a browser. No build step is required.
